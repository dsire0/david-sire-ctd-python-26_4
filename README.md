# Homework for Intro to Python with Code the Dream

## Reference Guide & Shortcuts

### Editor Shortcuts (VS Code / Antigravity IDE)

| Action | Shortcut (Windows) | Description |
| :--- | :--- | :--- |
| **Parameter / Signature Help** | `Ctrl` + `Shift` + `Space` | Reopens parameter info inside function calls like `print(...)`. |
| **Hover / Documentation** | `Ctrl` + `K`, `Ctrl` + `I` | Opens definition, documentation, and type hints for symbol under cursor. |
| **IntelliSense Suggestions** | `Ctrl` + `Space` | Reopens the autocomplete and suggestion menu. |
